 💰 AI Finance Assistant

An Agentic AI financial assistant built using Google ADK, Gemini,
Google Search and Streamlit.

## 🚀 Live Demo

[👉 Open AI Finance Assistant](http://192.168.1.36:8501)

## Features

- 💰 Personal finance analysis
- 📊 Expense analysis
- 💵 Saving plans
- 🎯 Financial goal planning
- 📈 Current stock information
- 📰 Latest financial news
- 🤖 Multi-agent architecture
- 🔎 Google Search integration
